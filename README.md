# 🍔 Foodies Hub

A food ordering web application with separate interfaces for users, managers, and admins — built to practice real-world frontend structuring with JavaScript.

---

## ✨ Features

- User-facing food ordering interface
- Manager dashboard for handling orders/operations
- Admin panel for managing the platform
- User profile page
- Interactive UI with dynamic content using JavaScript

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

---

## 📂 Project Structure

- `index.html` — Main landing/ordering page
- `manager_dashboard_07.html` — Manager dashboard interface
- `profile.html` — User profile page
- `admin.js` — Admin panel logic
- `script.js` — Core interactivity and functionality
- `style.css` / `features.css` — Styling

---

## 🚀 Future Improvements

- Connect to a backend/database for real order management
- Add user authentication
- Rebuild with React.js for better component structure
